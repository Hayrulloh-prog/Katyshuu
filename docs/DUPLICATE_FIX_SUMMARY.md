# Исправление проблемы дублирования записей при сканировании QR-кода

## Описание проблемы

При сканировании QR-кода система создавала дублирующиеся записи:
- Первый скан во втором цикле записывал 3 раза вместо 1
- Последующие сканы записывали по 2 раза вместо 1
- Записи появлялись не по порядку сверху вниз

## Причины проблемы

1. **Отсутствие проверки на дубликаты** - система не проверяла, была ли уже создана запись за последние несколько секунд
2. **Быстрые последовательные запросы** - клиент мог отправлять несколько запросов одновременно
3. **Недостаточная защита на сервере** - не было проверки по времени создания последней записи

## Исправления

### 1. Защита на сервере (attendance.js)

Добавлена проверка на дубликаты за последние 5 секунд:

```javascript
// Проверяем, есть ли уже точно такая же запись за последние 5 секунд
const fiveSecondsAgo = new Date(Date.now() - 5 * 1000);
const duplicateRecord = recentRecords.find(record => {
  const recordTime = new Date(record.createdAt);
  return recordTime > fiveSecondsAgo;
});

if (duplicateRecord) {
  console.log('Duplicate record detected:', duplicateRecord);
  return res.status(400).json({ error: 'Пожалуйста, подождите перед следующей отметкой.' });
}
```

### 2. Защита в QR-сканере (qr.js)

Аналогичная проверка добавлена в функцию `handleAttendance`:

```javascript
// Проверяем, есть ли уже точно такая же запись за последние 5 секунд
const fiveSecondsAgo = new Date(Date.now() - 5 * 1000);
const duplicateRecord = recentRecords.find(record => {
  const recordTime = new Date(record.createdAt);
  return recordTime > fiveSecondsAgo;
});

if (duplicateRecord) {
  console.log('Duplicate record detected in handleAttendance:', duplicateRecord);
  return res.status(400).json({ error: 'Пожалуйста, подождите перед следующей отметкой.' });
}
```

### 3. Улучшение защиты на клиенте (QRScanPage.jsx)

Уменьшено время ожидания между запросами с 10 до 5 секунд:

```javascript
// Было: 10000ms (10 секунд)
if (currentTime - lastRequestTime < 10000) {

// Стало: 5000ms (5 секунд)  
if (currentTime - lastRequestTime < 5000) {
```

## Как теперь работает система

### Защита от дублирования:
1. **Серверная проверка** - каждая запись проверяется на наличие дубликатов за последние 5 секунд
2. **Клиентская защита** - запросы блокируются на 5 секунд после предыдущего
3. **Флаг обработки** - одновременные запросы блокируются флагом `processing`

### Правильный цикл работы:
1. **Первое сканирование** → check-in (создается запись #1)
2. **Второе сканирование** → checkout (обновляется запись #1)  
3. **Третье сканирование** → check-in (создается запись #2)
4. **Четвертое сканирование** → checkout (обновляется запись #2)
5. **И так далее...**

### Ограничения:
- Минимальный интервал между отметками: 5 секунд
- Максимум 5 полных циклов (приход-уход) за 24 часа
- Каждая отметка создает только ОДНУ запись
