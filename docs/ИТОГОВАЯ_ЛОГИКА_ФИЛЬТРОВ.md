# ИТОГОВАЯ ЛОГИКА ФИЛЬТРОВ - СВОДКА

## ✅ РАЗДЕЛЕННАЯ ЛОГИКА ДЛЯ АНАЛИТИКИ И ТАБЛИЦ

### 📊 **АНАЛИТИКА (графики и статистика) - показывают последние 7 дней по умолчанию:**

**Функции:**
- `/stats` - статистика 
- `/chart` - данные для графиков

**Логика:**
- `today`: **ПОКАЗЫВАЕТ ПОСЛЕДНИЕ 7 ДНЕЙ** (по умолчанию)
- `week`: Последние 7 дней
- `month`: Последние 30 дней  
- `threemonths`: Последние 60 дней

### 📋 **ТАБЛИЦЫ (списки сотрудников) - показывают точные периоды:**

**Функции:**
- `/aggregated-status` - таблица всех сотрудников
- `/employees/absent` - таблица отсутствующих
- `/all-cycles` - таблица циклов
- `/employee-history/:employeeId` - история сотрудника

**Логика:**
- `today`: **ТОЛЬКО СЕГОДНЯ** (текущий день)
- `week`: Последние 7 дней
- `month`: Последние 30 дней
- `threemonths`: Последние 60 дней

## 🎯 **РЕЗУЛЬТАТ ДЛЯ ПОЛЬЗОВАТЕЛЯ:**

1. **В интерфейсе выбрано "Сегодня"** 
2. **Аналитика (графики, статистика)** показывает последние 7 дней - более полезная информация
3. **Таблицы** показывают данные только за сегодня - точная информация за выбранный период
4. **При выборе "Неделя"** и аналитика, и таблицы показывают последние 7 дней

## 🔄 **ЛОГИКА РАБОТЫ:**

- **По умолчанию** - пользователь видит аналитику за неделю (полезно для общей картины)
- **Таблицы** - показывают точные данные за выбранный период (полезно для детального анализа)
- **Согласованность** - при выборе "Неделя" все данные показывают одинаковый период
