# Инструкция по тестированию исправленной системы

## 🔧 Исправленные проблемы

### ❌ Проблема: При втором скане сразу показывалась форма регистрации
**✅ Решение**: Теперь при втором скане показывается выбор провайдера аутентификации

### ❌ Проблема: Данные OAuth (email, provider) не передавались в форму регистрации
**✅ Решение**: Исправлена передача данных через `authData.userData`

### ❌ Проблема: Токен не использовался корректно в запросах
**✅ Решение**: Теперь используется токен из `qrData` вместо глобального

## 📋 Порядок тестирования

### 1. Первый скан QR-кода
1. Откройте страницу `/qr/8KpW3Lm2QzX5Vb7F1YgR0tH9DqNcE6sJ`
2. **Результат**: Должен перенаправить на регистрацию менеджера
3. **Проверить**: В консоли должно быть "First scan - redirecting to manager registration"

### 2. Второй скан QR-кода (после регистрации менеджера)
1. Откройте страницу `/qr/8KpW3Lm2QzX5Vb7F1YgR0tH9DqNcE6sJ`
2. **Результат**: Должен показать выбор провайдера (Google/Apple)
3. **Проверить**: В консоли должно быть "Second scan - employee registration"
4. **Проверить**: Должен появиться компонент `AuthSelection`

### 3. Выбор провайдера и OAuth
1. Нажмите на кнопку Google
2. **Результат**: Должен перенаправить на OAuth
3. **После OAuth**: Вернуться на страницу с данными пользователя

### 4. Проверка существующих аккаунтов
1. После OAuth система проверит существующие аккаунты
2. **Если аккаунтов нет**: Перейдет к форме регистрации
3. **Если аккаунты есть**: Покажет выбор аккаунта

### 5. Регистрация сотрудника
1. Заполните форму регистрации
2. **Результат**: Должен успешно зарегистрировать
3. **Проверить**: В запросе должны быть `email`, `provider`, `googleId`

## 🚨 Если проблемы остались

### 1. Если все еще показывает форму регистрации при втором скане:
- Проверить консоль на наличие "Second scan - employee registration"
- Убедиться что `setCurrentView('auth-selection')` выполняется

### 2. Если данные OAuth не передаются:
- Проверить что `authData.userData` содержит данные
- Убедиться что `EmployeeRegistration` получает `userData` пропс

### 3. Если регистрация не работает:
- Проверить что в запросе есть все необходимые поля
- Убедиться что `managerId` передается правильно
