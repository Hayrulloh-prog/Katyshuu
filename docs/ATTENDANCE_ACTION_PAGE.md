# Страница определения прихода и ухода (AttendanceActionPage)

## Обзор
Новая страница `AttendanceActionPage` позволяет сотрудникам выбирать действие "Я пришел" или "Я ухожу" для отметки рабочего времени.

## Функциональность

### Основные возможности:
- **Заголовок и описание**: Понятный интерфейс с объяснением назначения страницы
- **Информация о последнем действии**: Показывает когда сотрудник последний раз пришел или ушел
- **Кнопки действий**: Кнопки "Я пришел" и "Я ухожу" для отметки времени
- **Валидация**: Предотвращение дублирования действий и неверной последовательности

### API endpoints:

#### 1. Получение последнего действия сотрудника
```
GET /api/employees/:id/last-action
```
- Возвращает информацию о последней записи посещаемости сотрудника
- Требует аутентификации
- Права доступа: сам сотрудник, супер-админ, менеджер сотрудника

#### 2. Выполнение действия (checkin/checkout)
```
POST /api/attendance/action
```
- Создает запись о приходе или уходе
- Тело запроса:
  ```json
  {
    "employeeId": 123,
    "action": "checkin" | "checkout",
    "timestamp": "2026-03-28T13:08:00.000Z"
  }
  ```
- Валидация:
  - Проверка прав доступа
  - Предотвращение дублирования (минимум 1 минута между одинаковыми действиями)
  - Проверка последовательности (нельзя два раза подряд выполнить одно и то же действие)

## Поток работы

1. **Сканирование QR кода** → QRScanPage
2. **Аутентификация** → Успешная аутентификация
3. **Перенаправление** → AttendanceActionPage
4. **Выбор действия** → Кнопка "Я пришел" или "Я ухожу"
5. **Сохранение** → Запись в базу данных
6. **Перенаправление** → CheckInSuccessPage или CheckOutSuccessPage

## Особенности

### Безопасность:
- Аутентификация через JWT токены
- Проверка прав доступа
- Валидация последовательности действий
- Предотвращение дублирования

### UX/UI:
- Анимированный интерфейс с Framer Motion
- Адаптивный дизайн с Tailwind CSS
- Информация о последнем действии
- Понятные сообщения об ошибках
- Индикация загрузки

### WebSocket уведомления:
- Реальное время обновления для менеджеров
- Отправка уведомлений при выполнении действий

## Использование

Доступ к странице осуществляется через:
- Прямой URL: `/attendance-action`
- После успешной аутентификации через QR код

Страница требует активной сессии пользователя (JWT токен в localStorage).
