# ИСПРАВЛЕНИЕ АНАЛИТИКИ - СВОДКА ИЗМЕНЕНИЙ

## ЗАДАЧА
Исправить аналитику, чтобы период "Неделя" показывал последние 7 дней, "Месяц" - последние 30 дней, "Два месяца" - последние 60 дней. Также аналитика по умолчанию должна показывать последние 7 дней, даже если выбран "Сегодня".

## ВНЕДРЕННЫЕ ИЗМЕНЕНИЯ

### 1. ИЗМЕНЕНИЯ НА СЕРВЕРЕ (server/routes/attendance.js)

**Исправлены все 6 функций:**
- `/stats` - статистика
- `/aggregated-status` - агрегированный статус
- `/employees/absent` - отсутствующие сотрудники
- `/chart` - данные для графиков
- `/all-cycles` - все циклы сотрудников
- `/employee-history/:employeeId` - история сотрудника

**Новая логика фильтров:**
- `today`: **ПО УМОЛЧАНИЮ ПОКАЗЫВАЕТ ПОСЛЕДНИЕ 7 ДНЕЙ** (вместо сегодняшнего дня)
- `week`: Последние 7 дней
- `month`: Последние 30 дней
- `threemonths`: Последние 60 дней (два месяца)

### 2. ИЗМЕНЕНИЯ В ИНТЕРФЕЙСЕ (client/src/pages/ManagerPanel.jsx)

**Обновлен компонент ManagerPanel:**
- Изменено начальное значение фильтра с `'today'` на `'week'`
- Во всех селектах изменен порядок опций - "Последние 7 дней" теперь первая опция
